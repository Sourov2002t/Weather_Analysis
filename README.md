🌡️ Delhi Heat Risk & Weather Analytics Dashboard

📌 Project Overview

This project analyzes historical Delhi weather data to understand heat patterns, assess public health risk, and present insights through an interactive Power BI dashboard.
The focus is on converting raw temperature and humidity data into meaningful heat risk indicators that can support awareness, planning, and decision-making.

🎯 Objectives

Analyze long-term weather trends in Delhi

Calculate heat index using temperature and humidity

Classify days into heat risk levels (Normal, Safe, Caution, Danger)

Identify high-risk periods that may impact public health

🗂️ Dataset

Historical daily weather data for Delhi

Key fields include:

Date

Max / Min / Avg Temperature

Humidity

Heat Index (derived)

🔍 Analysis & Logic

Data cleaned and transformed using SQL and Power Query

Feature engineering:

Heat Index

Temperature range

Humidity-adjusted metrics

📊 Dashboard Features

Heat risk status indicators

Monthly and yearly heat trend analysis

Identification of extreme heat days

Visual breakdown of risk levels over time

🛠️ Tools & Technologies

Power BI (DAX, Power Query)

SQL for data analysis

Excel / CSV for data storage

🌍 Impact & Use Cases

Supports heatwave awareness and early warning analysis

Useful for government, urban planners, and health agencies

Helps citizens understand dangerous heat conditions

Demonstrates real-world climate analytics using BI tools

📌 Key Takeaway

This project shows how climate data can be transformed into actionable insights using analytics and visualization, with a strong focus on public safety and real-world impact.
